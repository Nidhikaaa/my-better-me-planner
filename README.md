# My Better Me – Personal Planner

My Better Me is a personal productivity and daily planning web application designed to help users organize their daily activities, manage tasks, and build better habits.

## Features
- Daily planning
- Task management
- Personal productivity tracking
- Simple and user-friendly interface
- Organized daily schedule

## Technologies Used
- HTML
- CSS
- JavaScript

## Getting Started
1. Download or clone this repository.
2. Open the HTML file in your web browser.
3. Start organizing your day!
